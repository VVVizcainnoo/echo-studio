PRODUCT BRIEF / 01

回声：我的 AI 翻唱制作人

让不会使用音频软件的人，也能制作一段愿意保存或分享的个人翻唱。

用户与问题

目标用户：喜欢音乐、想用自己的声音创作，但不熟悉音频工具的人。

待验证痛点：录音准备复杂、音色转换参数难懂、结果不稳定，缺少明确的调整入口。

核心价值

提供个人参考录音，选择歌曲片段，由制作流程完成检查、转换与混音，再通过试听决定是否保存。

明星音色属于未来授权合作范围，首版使用个人音色。

首版范围

一个个人音色、两段短素材、任务状态、对比试听、参数调整、下载与反馈。

不包含社区、支付、公开音色市场和完整歌曲批量生成。

Agent 与 Harness

单 Agent 解释需求并选择允许的工具；Harness 校验输入、管理状态、限制重试、记录失败与执行结果。

当前交互版采用确定性流程，未连接大模型、音色转换或远程 API。

验证与指标

先邀请 3～5 人完成创作任务，观察独立完成率、卡点和保存意愿。接入真实生成后，再评估自然度、音色相似度、耗时与单次成本。

以上均为研究计划，暂无用户数据；演示试听不能验证翻唱质量。

交付与边界

9/23 完成演示与复盘，9/24 展示。优先零预算，不依赖购买显卡。

个人录音不上传、不持久保存。曲目示例为原创程序合成旋律；真实歌声与授权歌曲素材待接入。

USER JOURNEY / 02

从一段声音，到一份作品

用户掌握创作决定，制作人负责安排工具，执行框架负责可靠完成。

01

准备声音

上传 → 确认本人声音 → 检查文件

失败：提示格式、大小或解码问题，允许重新选择。
02

选择片段

选歌 → 调整音高与混音偏好

首版固定素材；不开放第三方歌曲抓取。
03

制作与检查

检查 → 转换 → 混音 → 保存结果

执行中锁定输入，可取消；失败后由用户重试。
04

试听与保存

前后对比 → 调整 → 下载 → 反馈

修改参数后重新制作；明确标记示例与真实作品。

执行状态

待准备 → 就绪 → 检查中 → 处理中 → 可试听

异常分支：输入不合法 → 返回准备；执行失败 → 保留输入并允许重试；取消 → 回到就绪。

真实能力接入顺序

① 验证参考音色转换效果　② 接入歌声转换工具　③ 加入真实音频质量检查　④ 根据需求增加大模型调参。

本版“制作记录”是演示状态机，不代表已调用模型或完成歌声转换。
